# Avisos de terceiros

O catálogo inicial contém somente questões originais do Silogium.

Importações futuras devem registrar, por questão: fonte, URL canônica, autores,
commit consultado, data de recuperação e texto integral da licença. O conector do
Exercism somente marca um exercício como importável quando o repositório do track
declara licença MIT; nenhum enunciado externo é copiado apenas com base no resultado
de uma pesquisa na web.
